Fill supported sweepstakes forms faster on Chrome or Microsoft Edge for Windows. You review everything and click submit yourself.

Install on your computer

  1. Download the ZIP and extract it to a folder.
  2. In Chrome, open chrome://extensions; in Edge, open edge://extensions.
  3. Enable Developer mode and select Load unpacked.
  4. Select the extracted extension folder, then pin the extension.
  5. Enter and save your profile in its popup. Open a sponsor's entry form and click Autofill current page.

Important: This is a manual-install browser extension, not a Chrome Web Store or Edge Add-ons listing. It has not been independently store reviewed. It does not submit entries, bypass CAPTCHAs, or work on iPhone Safari. Some sites block autofill.
