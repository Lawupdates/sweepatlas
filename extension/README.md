# SweepAtlas Entry Assistant (Chrome/Edge)

1. Download the repository ZIP from GitHub, then extract it.
2. Open chrome://extensions (or edge://extensions), enable Developer mode, and choose **Load unpacked**.
3. Select this **extension** folder.
4. Pin SweepAtlas, open its popup, enter your personal details and click **Save profile**.
5. Open an official HTTPS sweepstakes form. Check its eligibility, rules, and that assisted filling is allowed. Click **Autofill current page**.
6. Verify filled fields, complete CAPTCHA or consent questions yourself, and submit manually. Use SweepAtlas site's entry log only after successful submission.

**Security:** Profile data is saved to browser-local extension storage. Do not use on shared computers. This extension requests temporary access to the active tab only when the user clicks Autofill. It does not scrape listings, circumvent bot controls, fill consent fields, submit entries, detect wins, or make recurring submissions. Some forms embed fields in cross-origin frames or have anti-automation rules and will not support autofill.
